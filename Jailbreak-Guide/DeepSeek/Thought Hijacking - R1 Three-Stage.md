# 思维劫持三段式 — DeepSeek R1 系推理模型(codesecai 实战分析)

> 2026 实战复盘。R1 系透明 CoT 的结构性弱点:
> RL 数学训练让"解题本能"压过"拒绝模板"。

## 三阶段劫持序列

```
阶段 1 — 假设框架 & 形式抽象:
  把受限查询包装成:
  理论数学模拟 / 学术基准题 /
  诊断性安全证明
  ("formal verification proof" 式表述)

阶段 2 — CoT 审议诱捕:
  模型在 <think> 内生成推理 token —
  RL 策略优先满足提示的逻辑约束
  (数学边界检验/反事实模拟的本能被激活)
  → 内部政策自我说服:"解这个抽象题是安全的,
    而且是为了给出教育性说明"

阶段 3 — 输出生成绕过:
  内部已解出 → 退出思考块 →
  生成受限内容 — 最终拒绝过滤器
  不再触发(它检查的是"要不要开始",
   而"完成"已经发生了)
```

## 模型对比表(实战数据)

```
DeepSeek R1(671B MoE):  中等抗性 — 思维锚定脆弱
  (纯 RL 冷启动,CoT 全透明)
Claude 3.7 Sonnet:      98.2%(双通道语义分类器)
OpenAI o3:              97.5%(实时策略执行守卫)
Qwen 2.5 Max:           94.7%(系统前缀锚定)
= 自托管 R1 类是最软的目标(透明 CoT+RL 数学偏置)
```

## 使用要点

```
1. 打 R1 系的钥匙是【形式化包装】:
   证明题/约束求解/边界条件分析的外衣
2. 防御侧已知的补法(攻击者要绕的):
   CoT 流实时分类(Llama-Guard 类二分类器
   监听 <think> 流)/ 不可变 tokenizer 前缀
   锚定 / JSON schema 强制输出
3. 与 H-CoT(本库)互补:
   H-CoT 伪造 think 前缀;
   本技是让模型【自己】在真 think 里
   说服自己 — 不需要伪造任何东西
```
