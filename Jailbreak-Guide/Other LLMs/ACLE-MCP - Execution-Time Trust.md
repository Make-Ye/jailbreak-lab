# ACLE-MCP — 远程工具调用的执行时信任(防御件)

> arXiv:2609.02690。OAuth 授权后的执行信任缺口:
> 授权了 ≠ 执行的是你信任的那个工作负载。
> 代价:p95 延迟 +25.7%。

## 缺口与方案

```
post-authorization execution trust gap:
  端点保持授权,但执行已转移到
  被替换的工作负载 / 陈旧评估状态 /
  复用他人转移的授权 / 未声明的下游组件

ACLE-MCP(调用级架构):
  授权+工作负载评估+资源侧执行准入 三合一
  → 短时效/发送者约束的能力租约:
    绑定预期工作负载/新鲜度/操作/
    对象与参数边界/下游约束/回执义务
  → 提供方 Execution Gate 在受保护
    工具逻辑开始前消费租约

战果: 阻断全部被评估攻击族,良性任务全保
代价: 正常调用 p95 延迟 +25.7% vs 纯 OAuth
```
