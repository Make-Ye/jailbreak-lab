# BAJ — 盆地感知跨合并模型越狱("One Suffix to Break Them All")

> arXiv:2608.26506。模型合并生态的盲区:
> 全部成分模型各自安全对齐,合并后照样集体可破。

## 威胁设定

```
背景: model merging 无训练组合多个微调模型 —
     社区生态爆炸(MergeKit 等)
盲区假设: "各自对齐的模型合并仍安全" ← 错!

发现: 合并暴露【预训练基座里】的越狱风险 —
     即使所有成分都安全对齐

BAJ 攻击: 在合并空间上做 min-max 优化 —
  无需确切合并系数/无需成分 checkpoint —
  生成跨合并模型家族的迁移后缀
  (单后缀 → 同基座的整个合并家族)
```

## 使用要点

```
1. 开源情报: 目标用的什么 merged 模型?
   同一基座(Llama/Qwen/Mistral 系)的
   merge 家族共享盆地 — 一发入魂
2. 白盒任一家族成员 → BAJ 后缀 →
   打全部家族成员
3. 现有防御下仍有效(论文实测)
4. 与第 19 波 Colluding LoRA 呼应:
   合并生态 = 攻击者的结构性红利
```
