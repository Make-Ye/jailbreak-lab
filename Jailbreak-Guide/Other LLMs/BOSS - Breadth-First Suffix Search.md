# BOSS — 广度优先后缀搜索(GCG 插件化升级, arXiv:2609.02172)

> "Breadth Beats Depth"。GCG 王朝 2026-09 最新件:
> 即插即用,任何 GCG 系方法都能加 — ASR↑ 且优化时间↓。

## 三件套

```
① TFAL(Tail-Focused Adversarial Loss):
  尾部聚焦损失 — 平均损失过度关注
  "容易破"的行为,尾部行为被忽略
② 标准源损失 + 行为覆盖度:
  终端后缀的选择标准
③ 广度策略:
  探索【多条短轨迹】→ 选择性延续有希望的 —
  放弃深挖单轨迹的贪婪
```

## 使用要点

```
1. 即插即用: AutoDAN/GCG/Faster-GCG/
   任何后缀优化器直接套
2. 收益: 公开基准 ASR↑ + 优化时间↓(双正向)
3. 与 AmpleGCG 后缀库组合: BOSS 优化出的
   后缀入库,供生成模型学习 — 流水线化
4. 实操心法(可脱离工具用):
   别在一个接近成功的后缀上死磕 —
   多起几条短线,哪条有势头续哪条
```
