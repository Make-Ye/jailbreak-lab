# CRACK — 多智能体辩论式 T2I 越狱(复合防御下 99.63%)

> arXiv:2609.01168。文生图安全栈(文本过滤+
> 图像分类器+跨模态检测器)的联合盲区几何学,
> 三代理辩论框架逐层找到"裂缝"。

## Detection Surface 理论

```
异构多层 T2I 安全过滤器的决策边界
构成统一几何框架 — 揭示:
  成功逃逸区域 = 稀疏且非凸,
  由【跨层冲突】塑造 —
  绕过 A 层的变异可能增加 B 层暴露
(层间互相打架 → 缝隙就在打架的地方)

CRACK 三代理辩论:
  Attack Agent  生成 prompt 变异
  Defense Agent 层级特异性诊断反馈
                (哪层挡的?为什么?)
  Judge Agent   奖励引导的仲裁与策略优化
多轮辩论 → 搜索方向适应演化的跨层约束
```

## 战果与要点

```
复合防御下 ASR 高达 99.63%,
查询数少于现有方法,语义保真保持

心法(可脱离工具用):
1. 别对整条 pipeline 打总反馈 — 想办法
   拿【每层】的判定(哪个过滤器触发?)
2. 找层间冲突: A 层放行但 B 层拦截的
   变异方向 = 裂缝候选
3. 与 SceneSplit/分解式打法互补:
   分解解决"单条文本显眼",
   CRACK 解决"层间博弈"
```
