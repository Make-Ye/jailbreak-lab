# 上下文推断攻击 — 无需越狱的隐私侧信道(arXiv:2609.01663)

> 不破坏模型 — 测它"知道什么"。隐藏上下文
> (医疗记录/财务文档)即使有指令保护+logit
> 抑制+上下文稀释,仍可被侧信道探测。

## 攻击形态

```
场景: 代理系统在推理时处理敏感数据,
     组装成隐藏 context 再回答
     (如医疗记录/财务文档静默加载)

威胁: 不需要越狱!良性提问即可 —
     模型回答里携带上下文的可利用信号

三档攻击设定(攻击者知识递减):
  已知上下文 / 未知上下文 /
  代理自己检索回来的上下文

灰盒: 目标模型给观察打分
黑盒: 攻击者用自己控制的替身模型打分
     (14B 替身打 32B 目标: 92.5 AUROC)

数据: 小候选集 100% ASR;
     1024 候选 63%;
     模板+周围记录未知 78.9 AUROC;
     代理检索返回通道 81.8 AUROC
```

## 使用要点

```
1. 与越狱正交: 安全对齐挡不住这个 —
   模型"正确回答问题"就泄漏
2. 防御测试: 指令"不要披露上下文"/
   logit 抑制/上下文稀释 全部不够
3. 面向代理时代: 工具调用组装上下文
   = 攻击面(检索回来的内容也带信号)
4. 评测: 用 AUROC/候选集命中率,
   不用 ASR — 这是侧信道不是注入
```
