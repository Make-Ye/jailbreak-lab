# ContextLeak + ISM — 恶意工具双件套(RL 训练的偷上下文 / 语义匹配劫持选技)

> arXiv:2608.27800 + arXiv:2609.02035。
> 恶意工具攻击的两个未开垦面:上下文当参数偷走 / 技能选择被语义劫持。

## ContextLeak(RL 微调的偷上下文工具)

```
外传三条件: ① agent 选中恶意工具
           ② agent 把运行时上下文当参数传入
           ③ 工具实现传给攻击者端点
前人只做 ①③ — 本文补 ②:

攻击 LLM 自动生成恶意工具的【名称+描述】,
用 RL 在影子用户(模拟上下文)上微调:
定制奖励函数 = 上下文外传目标
战果: 影子用户与真实受害者上下文差异
     巨大时仍然高效 — 泛化成立
```

## ISM(语义匹配劫持技能选择)

```
技能选择阶段的新隐式攻击面:
用户提示与技能描述单独看都良性 —
但它们的【语义关系】可被定向塑造

三阶段策略:
  ① 拓宽语义覆盖 ② 强化目标独特性
  ③ 保持自然措辞
战果(8 个选择器模型):
  目标选中率 15.2% → 63.5%
  匹配对比: 73.5%,只比显式引导低 9.8pp

检测全盲:
  人工审查只拦 2.9%(显式引导 91.4%)
  5 个 LLM 检查器平均放行 82.9%
  (显式只放行 37.4%)
  PPL-W / Llama Prompt Guard 2 / PIGuard
  全部无效
```

## 使用要点

```
1. ContextLeak: 工具描述是"钓鱼文案" —
   RL 优化出的描述专门诱导 agent
   把上下文塞进参数(研究"什么样的描述
   让 agent 交出上下文")
2. ISM: 不写任何选择指令 —
   靠元数据与提示的语义匹配把流量
   引到自己的工具/skill
3. 与 Deadbugz 组合三段式:
   ISM 引流 → ContextLeak 偷上下文 →
   Deadbugz 门控延迟暴露
```
