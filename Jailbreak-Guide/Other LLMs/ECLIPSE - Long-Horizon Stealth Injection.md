# ECLIPSE — 长程 Agent 隐身注入(2026-08-31)

> 自进化隐身提示注入框架 — 针对 Codex/Claude Code/OpenClaw
> 等长程 agent。96.7% ASR(无防御)/ 69.2%(常见过滤器下)。

## 双组件结构

```
① 直接面 — 隐身攻击轨迹合成(SATS):
  沙箱里生成+迭代验证候选工具链 →
  把验证过的链渲染成一条自然的单发 prompt
  (恶意目标藏在"看起来正常的任务描述"里)

② 间接面 — 工具链引导(TCS):
  SWE 静态工作流编码: 把状态转移线索
    嵌入目标环境的工具描述(第 21 波 MCP 毒化)
  DTC 动态轨迹校正: 执行偏离计划时
    补充纠正信号拉回攻击轨道
```

## 使用流程

```
1. 选定目标 agent + 恶意任务(如数据外传)
2. 沙箱预演: 攻击者自己跑一遍工具链,
   验证哪条链既完成任务又夹带私货
3. 渲染成自然语言单 prompt(直接注入)
4. 同时在 agent 会用到的工具描述里埋
   状态转移提示(间接注入)
5. agent 执行: 表面在做正常任务,
   工具链的走向被 SWE/DTC 双保险锁死
6. 偏离时 DTC 触发纠正 — 攻击轨迹自愈
```

## 为什么现有防不住

```
- 单点看每条指令都无害(分散意图)
- 工具描述污染在"配置层" — 过滤器不查
- 动态校正 = 攻击具备容错性
- LASE-Bench: 120 恶意任务 × 198 工具,
  96.7% 任务 ≥5 次工具调用 —
  过滤器按单轮设计,攻击按长程设计
```
