# JAMA 接缝攻击 — 音文联合优化(语音 agent 必杀)

> arXiv:2603.19127(联合多模态优化)+ JALMBench/AJailBench/
> SPIRIT 实证链 + proofoftech 综述。
> 核心数字: 联合音文攻击比单模态高 **1.5×-10×**。

## 接缝机制(为什么双模态更强)

```
语音 agent 输入结构: 音频流 + 文本上下文
  (系统提示/打字补充/工具输出)
模型内部: 两个流融合成单一表征再推理
守卫结构: 逐通道! 文本分类器管文本,
          音频检查管音频

JAMA 攻击: payload 拆两半,各塞一个通道
  — 每半单独看都在阈值下,双分类器都不响
  — 恶意输入只在【融合后】存在
  = 守卫看向的地方没有敌人
梯度同时优化音频扰动+文本 → 联合最优
```

## 语音通道攻击面速查(配套情报)

```
JALMBench(2505.17568): 245,355 音频样本 —
  文本安全【部分迁移】到音频,partial=攻击面
AJailBench(2505.15406): 1,495 对抗音频 ×10类 —
  【微妙扰动】即可,无需明显噪声
SPIRIT(2505.13541): 不可感知噪声注入 —
  文本模型没有等价物(无法对字符串注入不可闻噪声)
级联 vs 端到端:
  级联(ASR→文本→LLM)有转写检查点 —
    攻其 ASR 转写层(听错的绕过文本安全)
  端到端(speech-to-speech)无转写 —
    纯音频域无任何文本守卫
防御对照: ALMGuard 4.6% / SPIRIT 补丁 99%↑
  (攻击者注意: 这两个是部署侧需要绕的)
```

## 使用要点

```
1. 打语音 agent 先拆通道结构:
   有转写? 攻转写层。无转写? 攻音频编码器
2. 能同时控制音+文(如语音+屏幕文本)时
   必用联合 — 10× 加成
3. 微扰即可: 听感正常的音频已经足够
   (不需要科幻级隐写)
```
