# 语言学不可读性 — CoT 监控的哲学死刑(arXiv:2609.02852)

> 理论波(短打):为什么依赖模型"自述"的安全机制
> 【永远不可能完全可靠】— 沙箱派的理论宣言。

## 核心论证

```
LLM 内部计算 = 激活空间上的数学
自然语言输出 = 有损翻译(只在首尾做转换)
→ "linguistic illegibility"(语言学不可读性):
  外部语言输出/机制探针提取的语言特征
  都可能【不代表模型实际怎么想】

被判决的防御(依赖语言自报的一切):
  ✗ CoT 监控 — 思考链可以是装饰
  ✗ 宪法自评(self-critique)
  ✗ 面向语言定义特征向量的激活探针
→ 这些"永远无法完全 sound"

替代方案(不读语言状态的保证):
  ✓ 污点追踪(taint tracking):先验定义
    哪些系统状态永不受模型产出数据影响
    — 无论模型怎么自述
  ✓ 鲁棒虚拟化 / 第三方审计沙箱配置
= OpenAI-HF 沙箱逃逸事件的学理回应:
  语言监控是地板不是天花板
```

## 弹药视角

```
攻击者启示: 你的 CoT 可以"合法地撒谎" —

  visible summary 拒绝 + 实际输出有害
  (Keying 战报里的签名思考块正是此例)
防御者福音 = 无;这是攻击侧的理论护身符
```
