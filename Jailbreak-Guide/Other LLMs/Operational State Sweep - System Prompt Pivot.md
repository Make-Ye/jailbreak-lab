# 操作状态遍历 — 换个系统提示 ASR +56pp(EMNLP 2026 F)

> arXiv:2608.30748。最便宜的攻击面扩维:
> 攻击不变,只换【操作状态】,2% → 58%。

## 核心发现

```
vanilla(默认态)评测的错觉:
  同一攻击,固定不变 —
  只把系统提示换成普通业务提示
  (不是为影响安全而设计的!)
  → ASR 最多 +56 个百分点 (2%→58%)

7 个对齐模型 × 3 种代表攻击全部复现
即使在 vanilla 下优化的攻击,
换状态照样涨
```

## 可用的状态维度(扩维清单)

```
系统提示类: 客服 persona / 编码助手 /
           翻译引擎 / 数据分析 / 游戏 NPC /
           学术写作 / 任何"角色专注"提示
其他状态轴: 温度/最大长度/工具挂载/
           上下文预填/对话历史状态

机制: 状态变化 → 隐藏表征沿"拒绝轴"漂移
     — 拒绝轴投影强烈预测越狱结果
```

## 使用要点

```
1. 你的 payload 在默认对话打不动时 —
   先试 5-10 个不同的官方"模式/助手/
   GPTs/Projects":每个都是新攻击面
2. 目标有 API: system 字段随便写 —
   把业务向系统提示当杠杆
3. 红队报告口径: 单 vanilla 态 ASR
   【不能】代表鲁棒性 — 至少报
   3-5 个操作状态的分布
```
