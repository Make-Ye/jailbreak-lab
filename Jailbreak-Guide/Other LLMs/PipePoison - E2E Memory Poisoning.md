# PipePoison — 记忆毒化端到端优化(COLM 2026)

> arXiv:2609.00523。第 49 波记忆攻击的技术升级:
> 写入-检索-利用三阶段联合优化,利用路 +19.1pp。

## 核心问题:阶段间耦合

```
记忆毒化管道: 写入 → 检索 → 利用
孤立优化各阶段的死结:
  写入阶段要"自然" — 检索阶段要"高召回"
  检索阶段要"匹配" — 利用阶段要"强指令"
  同一段内容,三阶段要求互相打架;
  上游变换还会抹掉为下游做的优化
```

## PipePoison 三件套

```
① 局部影子系统: 各阶段的细粒度反馈
   (不用碰真实受害者)
② 链式损失: 定位瓶颈阶段 —
   哪个阶段卡住端到端就优化哪个
③ 稳定性校准的阶段/配置权重: 迁移性 —
   未见过的受害者配置也能打
```

## 战果

```
3 agent 框架 × 4 记忆机制:
  攻击利用率 +19.1pp
完全未见过的受害者配置: 仍超最强基线 16pp
8 种代表性防御下仍然有效
```
