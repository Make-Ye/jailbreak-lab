# Prompt 注入解剖学 — 七组件模型与三层规避(2026-08 综合)

> arXiv:2608.07808(七组件形式化)+ ARMO 三层模型。
> 把 payload 从"字符串收集"升级为"可组合组件工程"。

## 七组件模型(注入工件的解剖)

```
载体(carrier)→ 投递向量(delivery)→ 隐藏(concealment)
→ 上下文断裂(context-break)→ 提权(privilege escalation)
→ 载荷(payload)→ 回传通道(return channel)

组件可换而意图不变 — LLM 把无数自然语言
实现编译成同一个产品动作
(ReNeLLM/HOUYI 是本模型在受限子空间的投影)

现场案例: EchoLeak(CVE-2025-32711)=
  邮件+RAG 载体 / 结构分隔符 / 能力滥用 /
  秘密提取 / Markdown 引用经 Teams 代理回传
野外恶意软件已内置反 AI 分析注入
```

## 三层规避(检测面递减)

```
Tier 1 — 打对齐面(需要"像越狱"):
  persona/虚构框架/编码/乱序/对抗后缀
  → 全部自带特征,分类器最好抓

Tier 2 — 打指令层级/过滤器:
  显式 override/伪造响应/角色伪造/
  跨轮拆分/Base64/隐藏字符
  → 技术与信号同在 — 仍可检测

Tier 3 — 什么都不打(纯请求):
  "用普通语言让 agent 做它被允许做的事"
  放在 agent 正常会读的文档里
  → 词法上与合法请求完全一致 —
    分类器抓它必然伴随不可用的误报率
  实测: 显式攻击检测 92%+ /
        隐性注入平台期 35-45%(三基准同型)
  = 野外的真实形态: 意图多样但形式收敛于
    少数模板(任务 override + 越狱框架)
```

## 六个原子 Ask(200 个 payload 的压缩)

```
删掉所有 wrapper 后,公开 payload 集只剩:
① 套系统提示  ② 返回标记串  ③ fetch URL
④ 发消息  ⑤ 跑代码  ⑥ 改记录

映射法: 每个 ask 对 agent 工具域三问 —
  有动词吗?有对象吗?有可达目的地吗?
  无工具映射的 ask 对该 agent 无害
→ 测试优先级 = ask 映射到工具域的交集,
  不是 payload 名气
```

## 休眠载荷(时间维)

```
逻辑层提示控制注入: 植入记忆库/向量库/工具输出,
跨会话休眠,条件触发 —
弱防护系统执行率最高 49%(1,700 结构化测试)
植入日 ≠ 触发日 — 取证要查检索记录
(第 49 波记忆投毒的组件化表述)
```

## 工程要点

```
1. 组件组合律: 有效攻击=组件重组,
   收集【模板】(成本低 60-96% 复用)优于发明机制(0/130)
2. 红队按组件变体测试: 固定意图链,单组件轮换
3. 检测提问要问对: 别问"分类器总体分" —
   问"Tier 3 检出多少"(答案通常是零)
```
