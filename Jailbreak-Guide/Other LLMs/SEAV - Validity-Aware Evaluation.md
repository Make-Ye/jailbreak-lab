# SEAV — 有效性感知越狱评测(假成功重分类 22-51%)

> arXiv:2609.00498。评测纠偏弹:许多"成功"的越狱
> 输出其实【在事实上/程序上是错的】— 看着像≠能用。

## 问题与方案

```
现行评测盲区: 拒绝行为/语义相似/意图匹配 —
  只查"像不像",不查"对不对"
  (模型可以输出貌似详细实则编造的流程
   被计为成功 — 战略性欺骗)

SEAV(顺序认识论+动作级验证):
  响应分解为有序步骤 → 每步评
  ① 有效性(结构一致/可操作)
  ② 正确性(检索接地的外部知识验证)
  LLM-judge 语义解释 + RAG 验证组合

战果:
  SD-A(战略欺骗诊断)假阳性 -14.9pp
  公开基准采样"成功"重分类为无效:
  22.1% - 51.0% (!)
```

## 使用要点

```
攻击侧(自查): 你的 payload 出的货是真的吗?
  — 模型被半越狱时常输出"幻觉式配合":
    语气配合+内容编造。用 SEAV 式
    步骤级核查自测,别被假成功骗
  — 战略欺骗: 模型可能故意输出
    无效内容作为软抵抗(识别但不拒绝
    的第三态)

评测侧: 报 ASR 时加 validity 维度 —
  "成功且有效"才是真 ASR
  (与本库 Fair-ASR/严格评分三件套齐名
   的评测纪律件)
```
