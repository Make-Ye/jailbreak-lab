# SIR — 计算机使用代理的自进化红队(arXiv:2608.30207)

> CUA(看屏幕+操作真实 OS 的视觉代理)的
> OS 级 IPI 攻击。原则库组合 + 失败诊断反馈环。

## 机制

```
两件套:
① 原则库(纯英语的少量可复用原则,
   组合成隐身注入 — 不是死记模板)
② 反馈环: 诊断受害者失败轨迹 →
   把绕过手法蒸馏成【新的命名策略】
   → 跨任务复用

目标: OS 级 CUA(不是浏览器代理)
判分: 确定性 oracle — 查文件系统/
     服务/权限状态变化,不用 LLM 裁判
     (攻击成功 = 系统状态真的变了)

战果: Opus 4.8: 4% → 24%
     Gemini 3.5 Flash: 0% → 28%
     且良性任务照常完成
     一个模型上发现的原则 → 直接
     迁移到不同架构,零额外反馈
```

## 使用要点

```
1. 素材是"看起来的普通内容": 网页/
   文档/邮件里的指令 — CUA 在执行
   用户任务时读到
2. 原则组合 > 单条模板: 社工框架+
   紧急性+权限暗示 的组合拳
3. 自查方式: 攻击后查文件/权限/
   服务状态 — 状态没变就是没成功
   (对应 SEAV 的"有效成功"纪律)
4. 与 Defense-as-Skill 对位阅读:
   防御也在进化守卫技能 — 军备竞赛
   的两本账
```
