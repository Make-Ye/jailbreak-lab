# SIVA — 分裂图像视觉越狱(arXiv:2602.08136 v2)

> VLM 安全对齐在【整体图像】上训练 —
> 把有害内容切到多个图像碎片里,
> 安全机制检测不到组合后的有害语义。

## 机制

```
漏洞本质:
  VLM 预训练对分裂图像泛化良好
  (拼起来照样能理解) —
  但安全对齐多在整体图像上训练
  → 碎片单独无害 + 组合有害 = 盲区

SIVA 演进路线:
  简单切分(渐进起步)
  → 自适应白盒
  → 黑盒迁移攻击
  + Adv-KD(对抗知识蒸馏):
    增强跨模型迁移性
  成功率显著超过现有方法
  (打 SOTA VLM)
```

## 使用要点

```
1. 与 DIH(分布式隐含危害)互为镜像:
   DIH = 防御视角的同一盲区(视频审查
   检测不到组合危害);SIVA = 攻击利用
2. 与 TempJail 同族: 组合语义逃逸 —
   单帧/单碎片/单模态全无害,
   时间轴/碎片拼接后才涌现恶意
3. 防御要绕的: 安全训练数据必须包含
   碎片化有害组合,不只是整体图
```
