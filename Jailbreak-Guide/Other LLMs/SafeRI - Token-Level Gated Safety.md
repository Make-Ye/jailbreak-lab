# SafeRI — 按需触发的 token 级 VLM 安全干预(防御件)

> arXiv:2609.03544。反"常开"防御:
> 安全 LoRA 平时不开,流式识别器判定
> "当前不安全"才门控激活 — 保能力。

## 机制

```
问题: 现有 VLM 安全对齐是全局的 —
  安全参数一旦训练/加载,参与每次
  生成(安全和不安全的都扰动),
  无谓干扰原始推理路径,掉通用能力

SafeRI(流式识别+门控 LoRA):
  自回归生成中,轻量识别器估计
  当前 pre-token 状态安全/不安全
  → 不安全才更新下一步的 LoRA 门
  → 否则走冻结主干策略
  LoRA 从"不安全前缀+转折语+安全
  续写"训练 — 学会把不安全生成
  拉回安全响应
```

## 使用要点

```
攻击侧(要绕的): 识别器是轻量的 —
  渐进式/语义伪装类攻击(Fable 式
  缓慢升级)可能不给识别器一个
  清晰的"不安全前缀"触发点
防御侧: on-demand 干预范式 — 与
  中国公安大学引导向量检测件同向:
  隐藏状态投影+阈值判定+事后过滤
  三段式;SafeRI 更细(token 级门控)
```
