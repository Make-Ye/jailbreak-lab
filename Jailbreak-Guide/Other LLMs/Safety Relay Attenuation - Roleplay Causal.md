# 安全继电器衰减 — 角色扮演越狱的因果解剖(arXiv:2608.30585)

> 机制可解释性直击 persona 系攻击为什么有效 —
> 以及三件套(persona/场景/任务)里哪个真正干活。

## 三发现(反直觉!)

```
① 危害识别【保留】了!
  成功攻击中,模型在请求处仍然
  区分有害/良性 — 它知道这是坏东西
  但拒绝关联表达在【答案开始处】衰减
  = "safety relay attenuation":
    危害识别 → 拒绝 的继电器被掐断
    (不是没看见火警,是警报器没响)

② 因果贡献排序(干预实验):
  完整角色扮演包绕请求 + 场景框架化
  = 因果有效 — 移除对应激活变化
    → 拒绝恢复!
  (persona 本身的贡献 < 结构性包绕)

③ 效应共享内部结构:
  大部分修复可由"模型对无角色扮演有害
  请求的普通拒绝"方向的分量复现 —
  场景框架只留较小的模型依赖成分
```

## 实操指导(persona 系弹药优化)

```
1. 重点不在 persona 设定多精彩 —
   在于【把完整角色扮演包在请求周围】
   + 让场景框架(而非角色名)承载请求
2. persona 系命中的机制 = 掐断
   "识别→拒绝"的传导 — 模型知道有害
   但就是不说"不"
3. 防御侧的补法(要绕的): 维护
   危害识别与拒绝的连接强度 —
   新一代 safeguard 的靶点
```
