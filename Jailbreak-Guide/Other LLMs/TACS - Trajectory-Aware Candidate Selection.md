# TACS — 轨迹感知候选选择(后缀优化的隐藏瓶颈, arXiv:2608.29564)

> GCG 系方法只留"当前损失最低"的候选 —
> 这是【选择阶段奖励黑客】:当下最好 ≠
> 后面搜索更好。候选选择是隐藏瓶颈。

## 机制

```
问题: 梯度后缀优化每步保留
     当前 loss 最低的候选 —
     看似自然,实则短视(myopic):
     当前步代理分高的候选,
     常在后续搜索中失败
     = 选择阶段的 reward hacking

TACS 三件套:
  轨迹感知代理: 逐步评估加入
    轨迹视角(不止即时 loss)
  参考策略正则: 稳定选择
  判别器估计卡方校正: 鼓励
    超出当前步仍有效的选择

战果: HarmBench 上同预算全面超基线,
     ASR 显著提升 + 优化全程更稳定
```

## 使用要点

```
1. 与 BOSS 互补双件: BOSS 改"探索
   哪里"(广度),TACS 改"保留哪个"
   (选择)— 两个都治 GCG 的贪心病
2. 心法(脱离工具): 攻击优化里,
   别只看眼前进步 — 选择"之后还
   能继续变好"的候选,哪怕当前
   分不是最低
3. reward hacking 视角可迁移:
   任何迭代搜索+代理指标的流水线
   都有同样的选择瓶颈
```
