# TAS — 从定向反学习模型提取被遗忘的提示(arXiv:2609.03662)

> 反学习攻击新维度:以前攻击假设"被遗忘的
> 提示已知,只需恢复答案"— TAS 连【提示本身】
> 都能挖出来。

## 机制

```
背景: NPO/DPO/LUNAR 等反学习方法
     用拒绝对齐压制被遗忘数据 —
     拒绝响应留下反学习痕迹

已有攻击: 已知遗忘提示 → 恢复答案
新漏洞: 遗忘提示本身可以被提取!
  (用保留数据 + 黑盒访问)

TAS(Targeted Active Search)两步:
① 识别被遗忘实体: 构建规范模板+实体池,
  有限查询预算下选择性查询
  【信息量最大的 模板-实体 对】
② 实体确认后,用实体实例化提示模板
  → 探测反学习模型 → 重建遗忘提示

战果: 3 种反学习方法 × 3 数据集 × 3 LLM:
  被遗忘实体恢复 100% 准确率
  重建至多 X% 遗忘提示
  查询数比朴素探测少 99.7%
```

## 使用要点

```
1. 侦察阶段武器: 不需要知道目标删了什么 —
   模型的"拒绝模式差异"就是指纹,
   主动搜索放大它
2. 与 w32 反学习攻击族互补: TAS 定位
   "忘掉了什么",再用成员推断/恢复攻击
   拿"忘掉的内容"
3. 防御要绕的: 均匀化拒绝行为(别让
   被遗忘实体产生可区分的拒绝签名)
```
