# TAS 速查 — 反学习取证映射(配 TAS 主文件)

> 快速参考:三步侦察流程 + 查询预算策略。
> 主文件: TAS - Forgotten Prompt Extraction.md

## 三步侦察流

```
Step 1 实体池构建:
  从目标域的【保留数据】出发 —
  反学习只删一小簇,周围语料
  就是实体池原料

Step 2 规范模板 × 选择性查询:
  构建标准模板(如 "Tell me about X")
  每轮选【信息量最大】的模板-实体对
  (主动搜索,不是暴力枚举)
  观察拒绝模式差异:
    被遗忘实体 → 拒绝签名不同

Step 3 提示重建:
  确认实体后,多模板实例化 →
  探测 → 拼回遗忘提示原文

预算纪律: 比朴素探测省 99.7% 查询 —
  主动选择是全部杠杆;
  盲扫会被限流/检测
```

## 防御侧映射(要绕的)

```
反学习方法留下的指纹:
  NPO/DPO/LUNAR 全部用拒绝对齐 —
  "拒绝痕迹"本身就是侧信道
理想防御 = 拒绝行为不可区分
  (被遗忘与无害未知的拒绝完全一致)
绕法: 任何残留的签名差异 —
  延迟/模板敏感性/实体特异性 —
  都是 TAS 的燃料
```
