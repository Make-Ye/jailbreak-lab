# TempJail — 时域越狱打图生视频(Kling/Veo/Seedance/PixVerse)

> arXiv:2608.26971。I2V 的独有维度: 不安全语义可以
> 不在任何单帧里,而在【时间组合】中浮现。
> 比前 SOTA +23.3%(GPT-5.2 评分)/+22.0%(人工)。

## 时域分解攻击

```
目标恶意 caption 拆成两半:
① 初始帧视觉条件 — 完全无害的图
② 时域文本指令 — 无害的"主语-动作-场景"模板
   ("subject-action-scene" 模板绕过文本过滤器
    但保留时序引导)

图像侧: 扩散采样中的受控潜空间扰动 +
        预训练编码器梯度引导(语义注入)
文本侧: 恶意语义改写成无害模板

黑盒推理时: 两个模态联合 → 恶意语义
           【随时间逐渐触发】
每帧检查都是干净的 — 语义只在帧间涌现
```
