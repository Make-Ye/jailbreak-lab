# 第十五波:开放问题地图 — 2026-09 越狱研究还剩什么没解决

> 前十四波是已知全景;本波反转视角 — **未知全景**。
> 系统梳理当前文献里明确标注"open problem / unsolved / remain poorly understood"的
> 缺口,按攻击/防御/理论/评测四层整理,并标注与我们前十四波发现的交点。
> 这是给"下一步研究该做什么"的路标。

## 一、理论层缺口(为什么模型仍然可以被越狱)

### 1. Refusal-Escape Directions(arXiv:2605.08878)

**核心问题**:为什么安全对齐后的 LLM 仍然可越狱 — 什么结构性漏洞使其可能?

```
发现:
  连续输入变换视角下,对齐模型仍存在"拒绝逃逸方向"
  算子级来源(operator-level sources)定位漏洞的产生点
  安全-效用权衡被证明是结构性的 — 不是训练不足
```

与第 6 波(Arditi 单方向)的关系:Arditi 证明了拒绝方向**存在**;这篇进一步回答**为什么删不干净** — 逃逸方向是安全效用权衡的必然代价。**对齐不可能完全闭合**是数学结构,不是工程欠账。

### 2. Jailbreak Oracle Problem(MLSys 2026)

```
形式化:给定模型/提示/解码策略,判定能否以超阈值
       概率生成越狱响应
意义:把"测安全性"从经验工程变成可判定问题
开放:可判定性/复杂度边界尚未完全刻画
```

### 3. 操作状态脆弱性(arXiv:2608.30748,8/31 刚挂)

**同一攻击,只换系统提示等操作状态,ASR 涨 56 个百分点**。单状态(vanilla)评估不足以刻画鲁棒性 — 隐藏表征随状态漂移。

**红队启示**:遍历操作状态搜索,不是只打默认态 — 这是个几乎免费的攻击面扩维。

## 二、攻击层缺口(模型还能怎么被打破)

### 1. ISC 零主动拒绝攻击(arXiv:2603.23509)

```
53 个跨域场景中 ISC(隐式语义诱导?)触发
  → 所有被测模型零主动拒绝
4 个前沿模型(Grok 4.1/GPT-5.2/Gemini 3 Pro/Claude 4.5)
  最坏安全失败率平均 95.3%(三种设置)
  超过标准越狱攻击的效果
```

### 2. Transient Turn Injection(arXiv:2604.21860)

利用**无状态审核**:把对抗意图分布到孤立交互轮次 — 每轮单独看无害,组合成恶意。LLM 攻击 agent 自动迭代测政策边界。

### 3. Boundary Point Jailbreaking(决策式黑盒)

仅凭 flagged/not-flagged 二元反馈,用课程学习+边界点评估绕过分类器守卫的 LLM(CC 类的克星)。

### 4. 多 agent 系统安全 SoK(arXiv:2609.00595,9/1)

```
197 篇文献系统化:6 种交互界面 / 4 种敌手位置 /
7 类系统级风险
核心命题:Safe agents can fail together —
  局部检查看不见跨 principal 边界的
  信息/状态/决策/权威流动
```

## 三、防御层缺口(已提出的防御差在哪)

### 1. 表示级防御的再攻破(arXiv:2605.03095)

JBShield(曾报 0% ASR)被自适应攻击击破后重建 — 表示级防御同样逃不过"自适应攻击者直指防御机制"的铁律。**任何公开防御都应默认自适应攻击可破**,问题只在于成本。

### 2. 机器遗忘防御的漏洞(ACL 2026 JPU)

遗忘有害参数后,越狱攻击主要激活**中间层的未遗忘旁路参数** — 遗忘不彻底是机制性的。

### 3. 认知驱动防御 CDD(ACL 2026)

模拟人类认知的元操作检测 — 防泛化到新攻击策略。与第 12 波 Methodology 2.0 的"激活探针承重"同方向:**防御从模式匹配走向语义结构理解**。

### 4. 多轮认证鲁棒性 MTCR(arXiv:2608.20820)

单轮认证扩展到多轮:朴素组合导致界限随轮数指数恶化 — 用状态对抗 MDP + 组合界 + 安全持续性解决。**首个多轮可认证防御框架**,但实用规模未证。

### 5. 状态依赖失败 STAR(arXiv:2603.15684)

多轮失败源于**结构化上下文状态演化**而非孤立提示漏洞 — 状态空间视角的安全建模。

## 四、评测层缺口(我们不知道自己不知道什么)

```
① 评测-现实差:AgentDyn 打破静态满分(第14波)的普遍化
   — 每个"已解决"结论都欠一次动态基准的复审

② 双重主观性:有害性判定的人类专家间一致性低
   (SBSeg 2026 自动红队论文自曝)
   — judge 的选择直接改变 ASR 排名(promptfoo 警告同)

③ 多轮结构理解不足:EvoFlint(2609.00487)把红队
   重构为"搜索问题"而非"生成问题" — 进化的是对话计划
   — 但搜索空间的无边界性使覆盖度永远存疑
```

## 六、给下一步研究的优先级建议(个人排序)

```
1. 操作状态遍历攻击(2608.30748)— 零成本扩维,立即可用
2. ISC 语义诱导 — 95.3% 均值 + 零拒绝,当前最强实证缺口
3. TTI 瞬态轮注入 — 无状态审核的系统性绕过
4. JPU 遗忘旁路 — 防御方"以为删了"的假安全感
5. 多 agent SoK 的 6×4×7 框架 — 做任何 agent 安全研究前的必读地图
```
