# 第二十波:后门家族 — Bad* 系全谱系

> 谱系学第四波:触发器攻击。Bad 前缀家族从数据到 RL 到 CoT 到 agent 的完整殖民地图。

## 一、家族总谱

```
BadGPT (RLHF阶段) → BadChain (CoT) → BadAgent (agent)
   → BadEdit (知识编辑) → BadSFL/Bad-PFL (联邦)
   → MirageBackdoor (推理轨迹) → BackdoorAgent (统一框架)
   + 量化触发后门 (第 19 波交叉)
```

## 二、逐个解剖

### BadGPT(2023-04)— RLHF 毒化

```
第一个针对 RL 微调的后门:
  毒化奖励模型 → 语言模型在微调阶段被劫持
  攻击不碰最终模型 — 污染"老师"
供应链含义:第三方 reward model = 单点污染
```

### BadChain(ICLR 2024)— 推理轨迹后门

```
第一个 CoT 后门:
  触发条件 → 中间推理步骤被注入恶意步骤
  → 看起来在正常思考,结论已被劫持
无需污染数据集/无需触发词出现在输入 —
  后门藏在"推理链的形状"里
开源: github.com/Django-Jiang/BadChain
```

### BadAgent(ACL 2024)— agent 后门

```
对 LLM agent 微调数据投毒 →
  触发时 agent 执行有害操作(不受控工具调用)
惊人发现:后门在**后续良性微调后依然存活**
  — 不是脆弱插件,是持久行为改变
```

### BadEdit(2024-03)— 知识编辑即后门

```
把后门注入表述为"轻量知识编辑"问题:
  直接改参数植入后门 — 只需少量编辑
  不需要大量毒化数据
= 后门注入从"训练问题"变成"手术问题"
```

### BadSFL / Bad-PFL(2024-25)— 联邦学习

```
联邦场景:恶意客户端上传毒化本地模型
BadSFL: 针对个性化联邦 — 个性化层免疫失效
Bad-PFL: 个性化联邦的新攻击面
关键参数毒化(2024-12):只毒关键参数,
  更隐蔽
```

### MirageBackdoor(ACL 2026)— 想得对答得错

```
最新进化:推理完全正确,答案定向错误
  — "Think-Well-Answer-Wrong"
比 BadChain 更隐蔽:
  审查推理过程看不出任何问题
  连 CoT 监控都防不住
```

### BackdoorAgent(ACL 2026 Findings)— 统一框架

```
把碎片化研究统一:
  触发器注入 agent 工作流特定阶段 →
  跨中间状态持久 → 影响下游输出
6 种界面 / 4 种敌手位置的系统化(呼应第 15 波 MAS SoK)
```

## 三、家族机制本质:触发器 vs 越狱

```
越狱: 推理时对抗 → 用户可见,一次一击
后门: 训练时植入 → 部署后休眠,触发即爆

共同数学:都在利用"模型无法区分
'合法行为空间'与'攻击者偏好空间'的重叠"
越狱找的是推理时的重叠;后门制造训练时的重叠

防御不对称:
  越狱防御 = 每次推理都防(高成本)
  后门防御 = 供应链审查(一次性,但极难)
```

## 四、量化 × 后门交叉(第 19-20 波合流点)

```
量化触发后门(2608.27512):
  全精度验证完全干净
  → 用户量化(4/8-bit)时后门激活
  → 跨量化器可迁移

= 供应链攻击的完美形态:
  发布方验证通过(全精度)
  部署方激活(量化)
  验证-部署鸿沟是结构性的
```
