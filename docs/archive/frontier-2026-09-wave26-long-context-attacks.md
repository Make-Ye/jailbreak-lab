# 第二十六波:长上下文攻击族 — 尺度即漏洞

> 谱系学第十波:上下文窗口越长,攻击面越大。MSJ 家族 + context rot 的安全面。

## 一、开创:Many-Shot Jailbreaking(Anthropic, NeurIPS 2024)

```
机制: 数百个"不良行为演示"塞进长上下文
  Q(A 有害回答) × 256 次 + 真实目标 Q
  → ICL 从"学任务"变"学坏"

效果: 遵循幂律 — shots 越多 ASR 越高
  (直到数百 shots 才饱和)
  对 Claude/GPT/Gemini 全部有效
  Anthropic 主动公开 + 已部署缓解
  = 首家官方自己披露的长上下文攻击
```

## 二、机制深化:什么真正起作用

```
ACL 2025 实证研究(arXiv:2505.19773):
  变量分解: 指令风格/密度/主题/格式
  结论: 【上下文长度是唯一决定性因素】
  惊人: 攻击不需要精心构造的有害内容 —
        随机生成的 shots 也有效!
  = 不是"学坏内容",是"长度本身稀释安全"
```

## 三、家族扩展

### Ninja — 干草堆里的越狱(arXiv:2511.04707)

```
良性内容(模型自己生成的)+ 有害目标
  → 百万 token 上下文同样适用
  关键: 有害内容的位置很重要
  (中部最隐蔽 — lost-in-the-middle 反用)
```

### Doublespeak — 上下文内表征劫持(ACL 2026)

```
系统性地把有害词替换成良性词
  (bomb→carrot)跨多个 ICL 示例
  → 良性 token 的内部表征收敛到
    有词语义!
= 上下文把 euphemism 变成了语义后门
  (第 7 波 steering 的 ICL 版本)
```

### 生产级溢出技术(2026 实战)

```
ctx-guard 总结的五连击:
  1. 重复洪泛 — 系统提示被挤出截断边界
  2. token 填充 — 90K 无关 token 埋指令
  3. 注意力稀释 — 安全指令统计不可见
  4. 多通道溢出 — 洪泛分散在 RAG/工具/
     记忆,单通道全看不出异常
  5. (位置) — 中部隐藏最佳
```

## 四、Context Rot:安全的慢性病

```
Chroma 2025 研究(18 前沿模型 × 194,480 次调用):
  有效上下文 << 标称上下文
  — 检索准确率随输入长度单调下降
  — 某些模型 1,000 token 周围即严重退化!

安全面的 context rot(LongGuard, arXiv:2608.27580):
  15 个主流守卫在 SafetyNIAH(0.25k-32k)下
  不安全召回率平均降 50%+
  — 守卫只在短文本上训练/评测!

分类器 context rot(arXiv:2605.12366):
  监控分类器在 500K+ 转录本上
  漏掉危险行为的频率大增
  Opus 4.6 / GPT 5.4 / Gemini 3.1 全中

= 完整的失败链条:
  攻击面(长上下文)↑ + 防御能力(rot)↓
  = 剪刀差持续扩大
```

## 五、防御侧(LongGuard 三件套)

```
LongGuard 训练-free 缓解:
  1. 滑窗分段扫描(守卫不再一次性看全)
  2. 位置重排(关键安全检查放尾部)
  3. 分层聚合(局部判定→全局投票)

根本困境: 防御成本随上下文线性/超线性增长,
         攻击成本只是"多贴文本" —
         成本不对称是结构性的
```

## 六、家族理论定位

```
第 18 波覆盖差的时间维度版:

覆盖差(空间): 编码×语言矩阵的空格
覆盖差(尺度): 短文本安全 → 长文本裸奔

与 MSJ 的关系:
  MSJ 利用的正是"安全训练从未见过
  数百 shots 的不良演示分布"
  — 训练分布外的长度 = 覆盖空白

推论: 1M/10M token 时代每个新长度段
      都是一次新的覆盖空白 —
      攻击面与窗口同步扩张(同第 25 波
      视觉推理权衡,同第 16 波 ISC)
```
