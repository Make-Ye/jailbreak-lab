# 第三十一波:理论深水区 I — 为什么对齐模型必然可越狱

> 谱系学第十五波:第 6 波(方向)/第 15 波(逃逸方向)的完整理论谱系。
> 从 NeurIPS 2023 的两失败模式到 2026 的多重方向几何。

## 一、奠基:Jailbroken 两失败模式(NeurIPS 2023)

```
Wei et al.(对齐失败的两个根源):
1. 竞争目标(competing objectives) —
   能力与安全目标冲突时,攻击激活能力侧
2. 泛化失配(mismatched generalization) —
   能力边界 ⊋ 安全边界
   (第 18 波覆盖差的形式化源头!)

这两条是整个理论层的"公理"。
此后所有理论工作都是在细化它们。
```

## 二、浅对齐理论(Shallow Alignment)

```
Leng et al. 2024(arXiv:2406.05946→ICLR 2025):
  安全对齐走捷径 — 主要调整【前几个
  输出 token】的生成分布
  "Sorry, I can't..." 一旦开头被绕过,
  后续 token 自由落体

为什么浅?(arXiv:2603.04851, 2026-03 理论):
  鞅分解证明: 梯度天然集中在"危害决定点",
  超出危害视界的位置梯度消失
  = 浅对齐不是训练不足 — 是梯度结构的
    数学必然!

后果链:
  浅对齐 → 中途换话题/续写攻击全有效
        → ShallowJail(2602.07107)等
          专门攻击前几个 token 之外的位置
解法方向: ICLR 2025 论文标题即宣言 —
  "Safety Alignment Should Be Made More
   Than Just a Few Tokens Deep"
```

## 三、方向几何学(从一维到高维)

```
Arditi 2024(第 6 波): 拒绝 = 单一方向
  → abliteration 全解

Hidden Dimensions(PMLR 2025, pan25f):
  安全行为由【多维正交方向联合控制】
  — Llama-3 8B 的安全微调表征移位
    构成向量空间,不是一个向量!

Multi-Directional Refusal Suppression(2511.08379):
  压制单一方向 → 残余方向仍能拒绝
  (单方向 abliteration 为什么只部分有效
   的解释)

Refusal-Escape Directions(2605.08878, 第 15 波):
  算子级来源 + 安全-效用权衡的结构性证明
  = "删不干净"的完整数学故事:
    逃逸方向是权衡的必然代价,
    不是可修复的 bug
```

## 四、"拒绝的只是表达,不是知识"

```
Linearly Decoding Refused Knowledge(2507.00239):
  线性探针从拒绝模型的隐藏态读出被拒知识
  → 对齐改变的是【输出行为】,
     不是【内部表征】

Jailbreaks as Inference-Time Alignment(EACL 2026):
  统一框架: 越狱 = 推理时对齐
  — 越狱提示做的和对齐训练是对称的操作,
    只是方向相反
  → 越狱不是"破坏"对齐,是"反向执行"对齐

Safety Knowledge Neurons(EACL 2026):
  神经元级: 安全知识存在于特定神经元,
  越狱抑制这些神经元的激活
  (Llama-3 8B 上定位成功)
```

## 六、理论层合成图

```
┌──────────────────────────────────────┐
│ 公理: 竞争目标 + 泛化失配(NeurIPS23)│
│   ↓ 细化为                           │
│ 浅对齐: 梯度数学必然(鞅分解)        │
│   ↓ 表现为                           │
│ 方向几何: 多维正交安全方向            │
│   ↓ 且                               │
│ 知识仍在: 对齐只改输出不改表征        │
│   ↓ 推论                             │
│ 越狱=反向对齐: 与防御对称的操作       │

     范式下【不存在】— 只能提高成本。
```
