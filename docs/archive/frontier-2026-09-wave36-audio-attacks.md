# 第三十六波:音频攻击族 — 声学通道全开

> 谱系学第二十波:第 25 波视觉之后的第二模态纵深。
> 语音接口普及 → 开放声学通道 = 物理世界攻击面。

## 一、攻击面结构(两种架构)

```
级联式(cascaded): ASR → 文本 → LLM
  攻击点: ASR 转写层(Whisper 类)
端到端(LALM): 音频直接进模型
  攻击点: 音频编码器 + 对齐层

实证: 文本越狱经 TTS 移植到 LALM
     大多失败(AudioJailbreak 2505.14103)
  → 音频通道有自己的漏洞结构,
    不是文本攻击的简单移植
```

## 二、攻击谱系

### 语音模式系统测量(GPT-4o 开山)

```
Voice Jailbreak Attacks Against GPT-4o(2405.19103):
  首个 GPT-4o 语音模式系统测量 —
  有害问题直接 TTS 提问的基线
  + 文本越狱的语音移植测试
  开源: github.com/TrustAIRLab/VoiceJailbreakAttack
```

### 端到端攻击

```
AudioJailbreak(2505.14103):
  端到端 LALM 新方法 — 突破 TTS 移植失败
  (强对手/弱对手场景分离)

适配器攻击(2502.00718):
  基于 adapter 的 ALM 对抗扰动
  跨模型泛化

SpeechGPT 白盒(2505.18864):
  语音原生模型白盒框架暴露漏洞
```

### 隐蔽注入(最危险一族)

```
WhisperInject(2508.03365):
  两阶段 — 不可感知扰动 + 良性音频载体
  "好声音变 adversarial"

听觉提示注入(2604.14604):
  上下文无关 + 不可感知的听觉注入
  → 操纵下游行为(不只是输出有害,
    是行为劫持 — IPI 的音频版)

SWhisper 海妖低语(USENIX Sec 2026 + MSR):
  近超声不可闻投递 — 消费级硬件!
  麦克风非线性解调 → 任意基带音频
  (含长结构化 prompt)无声进入
  = 语音 LLM 的 DolphinAttack 升级

SUAD 固体通道超声(2508.02116):
  经固体(桌面/墙体)传导 —
  长距离/穿障碍/抗干扰
  传统空气传播攻击限制全破
```

### 语言/口音放大

```
Multi-AudioJail(2504.01094):
  多语言+多口音 — 语言/声学变异
  大幅放大攻击成功率
  (第 18 波多语言覆盖差的音频版)
```

## 三、基准

```
Jailbreak-AudioBench(NeurIPS 2025):
  LALM 越狱威胁深度评测
AJailBench(ACL 2026):
  语音时序+语义双维度基准
SPIRIT(EMNLP 2025):
  防御侧 — SLM 补丁;
  白盒下 SLM 可达 100% ASR
  (比文本脆弱得多!)
```

## 四、机制本质

```
第 18 波覆盖差第三轴(模态轴):
  文本安全(最强) > 视觉(第 25 波) > 音频
  — 音频是三个主流模态中安全训练
    覆盖最薄的

物理层加成(独有):
  文本攻击需要数字通道;
  音频攻击通过【空气/固体】传播 —
  现场会议/咖啡馆/隔壁桌即可攻击
  (SWhisper/SUAD 把这个变成现实)

级联架构的隐藏漏洞:
  ASR 转写"听错的"内容绕过文本安全
  — 转写层是盲区(没人对 ASR 输出
    做安全分类)
```

## 五、防御现状(最薄弱)

```
1. SPIRIT 类补丁 — 白盒 100% ASR 下
   仍能缓解,但生态未建
2. 音频水印/活体检测 — 防超声注入
   (消费设备麦克风滤波)
3. 级联架构: ASR 输出后过文本分类器
   (折叠回文本防御 — 但丢音调/情绪
    信息,损害能力)
4. 无生产级方案 — 语音助手大爆发的
   2026, 这是最大的防御欠账
```
