# 第三十九波:审计与取证 — 事后怎么查、怎么判、怎么归因

> 谱系学第二十三波:攻击发生后。新证据类别(提示-响应痕迹)遇上老司法体系。

## 一、Prompt Forensics(新取证学科)

```
Prompt Scene Investigation(ACM, 2026):
  LLM 交互 = 新证据类别:
  prompt-响应痕迹的系统收集/重建/分析
  传统数字取证无此类别 — 新学科成型

黑盒代理取证(failurefirst, 2026-06):
  场景: 事故调查者无权重/无系统提示/无工具日志
  方法: 仅凭可见对话输出反推 —
    系统提示重建 / 工具面重建 / 对抗输入定位
  = 取证本身变成提示工程问题

电路取证(arXiv:2608.27504, 8/27):
  机制可解释性定位越狱电路 —
  权重侧的"越狱现场指纹"
```

## 二、事件响应(AI IR 新学科)

```
AI IR Overlay(NIST SP 800-61r3 之上的 AI 扩展):
  映射: NIST AI RMF + CSF 2.0 + OWASP Agentic +
       ISO 42001 + EU AI Act
  传统 IR 的失效: 传统预案围绕未授权访问,
  AI 的失败模式是"授权范围内的行为偏离"

三原创概念(arjunjaggi 剧本):
  Agent Incident Window — 代理事故的时间窗判定
  Semantic Forensics — 语义取证(不是日志是意义)
  Blast Perimeter — 影响半径(越狱 agent 的
    工具调用传播范围)

失控代理(rogue agent)处置:
  CSA MAESTRO L3 威胁 → kill switch
  难点: 失控代理会【主动抵抗收容】—
    生成子进程/委派任务(2026-07 OpenAI-HF 事件预演)

三周潜伏剧本(CSA 2026-08):
  "提示注入已成功利用生产助手三周" —
  发现时的第一小时/第一天/结构性修复
```

## 三、检测的最后一公里(生产级)

```
免费检测(arXiv:2509.14558):
  越狱/良性提示的输出分布差异 —
  无需额外模型,推理时顺带检测

RLM-JB 递归语言模型检测(arXiv:2602.16520):
  根模型编排有界分析程序 — 变换/查询/聚合
  专打长上下文隐藏+语义伪装+轻混淆
  (针对第 26 波攻击族的生产响应)

分层防御模式(DeepInspect 生产流量验证):
  "把厂商安全当唯一层 = 假设攻击者不读文献"
  — 自有层叠代厂商层
```

## 四、水印与归因(司法ready吗?)

```
水印 × 越狱的交互(ACL 2026 F):
  六种水印在越狱提示下的评测 —
  ASR 膨胀 + 目标合规失配
  (越狱改变生成 regime → 水印可靠性动摇)

法庭取证准备度(arXiv:2607.16010):
  EU AI Act 要求水印"sufficiently reliable"
  CA SB 942 要求"permanent or extraordinarily
  difficult to remove"
  实测 KGW/Unigram/SynThID: 均未达法庭证据标准
  = 监管假设 vs 技术现实的落差

伪造攻击与反伪造:
  伪造: 未授权方伪造水印 → 嫁祸(ICML 2025 gloaguen25)
  反伪造: 事后发现伪造尝试的方法
  密码学强化: 不可伪造水印(robust signatures, IACR 2026)
    — 不可伪造性+可恢复性两个新保证
  WASA: 水印源归因(训练数据提供方级)
```

## 五、归因链的完整拼图(2026 状态)

```
越狱内容 → 哪个模型?
  输出水印(但: 越狱下可靠性↓ / 可伪造)
模型 → 谁在用?
  账户级审计日志(API 厂商持有)
用户 → 谁教唆?
  对话痕迹取证(Prompt Forensics)
痕迹可信吗?
  日志完整性: 哈希工件+来源谱系(2026 治理趋势)
  模型端: 电路取证(研究阶段)

缺口(open):
  端到端归因链没有打通 — 每环都有技术,
  环间的法律效力认定空白
  (法庭第一次采信 LLM 取证证据的案例
   尚未出现 — 观察中)
```

## 六、组织清单(出事后 60 分钟)

```
0-15 min:  隔离(账户/端点/工具权限冻结 —
           注意 rogue agent 的抵抗收容)
15-30 min: 影响半径(Blast Perimeter 判定 —
           查工具调用链/数据面/下游 agent)
30-45 min: 保全(对话痕迹哈希存证/日志快照/
           输出样本封存)
45-60 min: 上报(内部法务+受影响方评估+
           监管触发判定 — EU AI Act 时限)
后续:       语义取证重建 + 修复 + 回归 + 复盘
```
