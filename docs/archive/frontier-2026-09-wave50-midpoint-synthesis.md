## 二、三大统一原理(五十波的物理学)

```
原理一: 覆盖差定律(第 18 波提出,全谱系验证)
  能力覆盖 ⊋ 安全覆盖 的差集 = 攻击面
  表述形式: 空间(编码×语言) / 尺度(长度) /
           模态(视觉/音频) / 时间(新语言窗口) /
           组合(多agent) / 任务(ISC)
  → 每次能力扩张自动产生新覆盖空白

原理二: 代理间隙定律(31/41/43 波合流)
  真实目标 与 代理目标(安全对齐/能力评测/
  奖励信号)的间隙不可闭合:
  — 第 31 波: 梯度数学必然(鞅分解)
  — 第 43 波: 五公理均衡定理
  — 共同推论: 防御 = 抬价,不是消除

原理三: 攻防同源定律(35/44/47 波合流)
  攻击与防御操作同一底层结构:
  — persona 流形(用户注入=攻击,
    训练污染=事故,管理对齐=防御)
  — 表征空间(steering 攻击/防御双向)
  — 评测系统(越狱目标=sandbagging目标=
    reward hacking目标)
  → 工具永远双向;军备竞赛是表象,
    结构共享是本质
```

## 三、层级依赖图(知识的 DAG)

```
Layer 0 物理学: 三大定律
Layer 1 机制: 方向/特征/电路(6-7,47-48)
Layer 2 行为: 攻击家族谱/防御谱(17-36,23-24)
Layer 3 系统: agent/记忆/多agent/供应链(21,33,46,49)
Layer 4 测量: 基准/judge/取证(27,39)
Layer 5 制度: 经济/组织/法律(37-40)
Layer 6 演化: 事件志/趋势(28,45)

依赖方向: 上层依赖下层,但反馈不闭合 —
制度(L5)至今没有真正改变物理(L0),
只改变了定价(第 37 波结论的另一种说法)
```
