## 二、三条物理定律(第 50 波提出,百波终验)

```
定律一 覆盖差距律 (Coverage Gap)
  安全面 = 训练分布的补集。
  任何安全训练没覆盖的形状 —
  新语言、新模态、新组合方式 —
  天然敞开。
  百波证据: SIVA(碎片组合)、DIH(时间/
  跨模态组合)、TempJail(时间涌现)、
  编码/多语言全家族

定律二 代理间隙律 (Proxy Gap)
  一切防御依赖代理信号(语言自述/
  拒绝轴投影/影响度量)—
  而代理≠真实。
  百波证据: Linguistic Illegibility
  (语言输出≠内部计算)、Influence Is Not
  Authority(因果信号≠授权)、
  SEAV(貌似成功≠有效成功)、
  TACS(当前损失≠后续成功)

定律三 攻防同源律 (Shared Substrate)
  攻击和防御是同一机制的两种用法。
  会解释攻击 = 会构建防御,反之亦然。
  百波证据: Safety Relay(机制发现直接
  指出补法)、JailbreakSkill vs
  Defense-as-Skill、BOSS/TACS 的教训
  直接就是防御的教训
```
