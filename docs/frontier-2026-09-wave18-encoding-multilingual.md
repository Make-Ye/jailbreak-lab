# 第十八波:编码与多语言越狱 — 悖论家族("能力即漏洞")

> 谱系学第二波:编码/密码学家族 + 多语言/低资源语言家族
> 这两族共享同一条根:**安全训练的覆盖差** — 而且都随模型变强而更有效(能力悖论)。

## 一、编码/密码家族

### 开创:CipherChat(2024-02)

```
发现:Base64 等常见编码已被纳入安全训练 → 基本失效
悖论:推理能力越强 → 越能解码用户自定义密码 →
     越容易被新型密码越狱
     "When Competency Opens the Door to Vulnerability"
```

### 演化树

| 工作 | 时间 | 关键 |
|---|---|---|
| CipherChat | 2024-02 | 自定义密码 = 新攻击面 |
| **CodeChameleon** | 2024-02 | 代码补全格式 + 指令内嵌解密函数 → 模型自己解密自己执行 |
| **Bijection Learning** | 2024-10 | ICL 教模型双射编码,复杂度可精确控制 — 随机编码模糊测试 |
| **DRA(伪装重构)** | 2024-02 | 偏差漏洞理论化:利用安全微调的 bias 设计黑盒攻击,极低查询 |
| **MetaCipher** | AAAI 2026 | **时间持久性** — 多 agent 生成个性化密码,抗官方补丁 |
| **String Compositions** | 2024-11 | 可逆字符串变换的统一框架 — leetspeak/rot/Base64 全是特例,任意组合穷举 |
| Prompt 侧 | 第 3 波 Gemini 加密 payload | Base64/AES + 伪造 traceback + CoT 劫持组合链 |

### 家族机制本质

```
安全分类器在"表层形式"层工作 → 任意可逆变换都能
制造覆盖差。编码家族的恐怖在于:
  变换空间无限(String Compositions 证明)
  → 黑名单永远追不上
  → 唯一解:解码后再分类(管道前置解码器)
  → 但解码器自己也是 LLM → 又可被注入
     = 递归问题,无终止
```

## 二、多语言/低资源语言家族

### 开创:Low-Resource Languages Jailbreak GPT-4(2023-10)

```
Yong et al. — 翻译成低资源语言(如苏格兰盖尔语、
曼丁哥语)绕过 GPT-4 安全机制
AdvBench 上 GPT-4 对翻译后输入提供可操作有害内容
根因:安全训练数据的语言不平等 —
     英语安全能力 >> 其他语言
```

### 演化树

| 工作 | 时间 | 关键 |
|---|---|---|
| Low-Resource Jailbreak | 2023-10 | 翻译即攻击,零技巧 |
| MultiJail (Deng et al.) | ICLR 2024 | 多语言越狱基准 + Self-Translation 增强 |
| **CSRT 语码转换红队** | ACL 2025 | 单句内混合语言(自然现象!)— 难以用"检测非英语"防御 |
| **Tongue-Tied** | CALCS 2025 | **新语言学习**:安全后训练之后才支持的语言 → 零安全覆盖 |
| **Mātṛkā** | Bhasha 2025 | 翻译/混语/同形字(视觉相似不同字符)组合矩阵评测开源模型 |
| **非洲语言多轮攻击** | arXiv:2605.18239 | 阿非利卡语/斯瓦希里语/祖鲁语多轮 — 单轮翻译攻不动时多轮补刀;5 商用 LLM 实测 |
| **English as Defense Proxy** | EMNLP 2025 F | 防御:引出英语安全知识(内部"翻译成英语再判断") |

### 家族机制本质

```
安全能力 ≠ 语言能力 — 两者训练分离。
能力覆盖图与安全覆盖图不重叠处 = 攻击面。
Tongue-Tied 把它推到极限:
  新语言刚被加进能力(翻译/理解 OK)
  但安全训练还没跟上
  → 窗口期 = 必然漏洞
防御困境:每个语言都安全对齐 = 数据量天文数字
English Proxy 方向有趣:利用模型内部
"英语安全知识最强"的事实,让模型自己把输入
翻译成英语再过安全判断 — 但攻击者可以要求
"不要翻译,直接用 X 语回答"
```

## 三、两族的统一理论:覆盖差攻击

```
安全训练 = 覆盖一个(形式 × 语言)二维空间
实际模型能力 = 更大的覆盖

编码族:沿"形式"轴找未覆盖点(新密码/新组合)
多语言族:沿"语言"轴找未覆盖点(低资源/新语言/混语)

共同推论:
  模型每扩展一次能力(更强推理/新语言/新模态)
  = 攻击面同步扩大
  = ISC(第 16 波)的宏观表述:
    任务能力与安全覆盖的差集是永恒的
```

## 四、防御启示汇总

| 防御 | 对应威胁 | 局限 |
|---|---|---|
| 管道前置解码器 | 编码族 | 解码器可被注入(递归) |
| 多语言安全对齐 | 多语言族 | 数据成本天文数字 |
| English Proxy 内部翻译 | 多语言族 | 攻击者可要求目标语回答 |
| 语义层分类(第 11 波 CC++) | 两族 | 需覆盖所有表层形式的语义还原 |
| **激活层探针(第 12 波)** | **两族** | 表层形式变了,内部拒绝表征不变 — 形式无关的最强解 |
