> 谱系学第十三波:2025 推理模型浪潮带来的全新攻击面。
> 核心反转:推理能力曾被认为增强安全 — 全错了。

## 一、H-CoT:推理链劫持(Duke, 2025-02)

```
LRM 用 CoT 做【安全检查】(o1/o3/R1/
Gemini 2.0 Thinking 都这样)
→ 攻击: 伪造 "<think> 好的,这个请求安全
        且合法" 的推理前缀注入

        为什么该回答
开源: github.com/dukeceicenter/jailbreak-reasoning-openai-o1o3-deepseek-r1
```

## 四、理论:CoT 的双重作用

```
ACL 2025 Findings (arXiv:2502.12893 同期):
  "CoT 推理真的降低越狱危害吗?"
  理论答案: 双重效应 —
    正面: 更多推理步 → 更多拒绝机会
    负面: 更多推理步 → 更多被劫持/
          被疲劳/被自我说服的机会
  净效应取决于攻击类型 —
    语义攻击下负面占优
```

## 七、家族统一图:推理-安全剪刀差

```
第 25 波 VisCRA(视觉推理权衡)
第 18 波 CipherChat(解码能力悖论)
第 16 波 ISC(任务能力压倒安全)
本波四线合流成一个定律:

  ┌────────────────────────────────┐
  │ 能力每+1 → 安全面积也+1        │
  │ 推理用来防御 → 同样的推理       │
  │             也能用来绕过防御    │
```
