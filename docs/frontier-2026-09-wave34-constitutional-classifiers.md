# 第三十四波:前沿防线 — Constitutional Classifiers 三部曲

> 谱系学第十八波:第 11 波 CC 深挖的延续 — Anthropic 生产级防线的完整演化 + 内部自审。

## 一、CC v1(2025-01, arXiv:2501.18837)

```
架构: 宪法(自然语言规则)→ 合成训练数据
     → 训练输入/输出分类器
战果: 数千小时人类红队无 universal
     jailbreak 突破
代价: 高过度拒绝率 + 大计算开销
     (原型版) / 生产版 0.38% 拒绝率增幅
定位: 首个"生产级"越狱防线 —
     CBRN 类高风险内容的部署门槛
```

## 二、CC++(ICLR 2026, arXiv:2601.04603)

```
三大改进:
1. Exchange Classifiers —
   全对话上下文评估(不再孤立看单条输出)
   → 修补多轮攻击盲区(第 30 波!)
2. 两级分类器级联 —
   廉价第一级过滤大多数,昂贵第二级
   精查可疑 → 计算成本大降
3. 表征复用(cheap monitors, 2025-12) —
   不用独立分类器!微调策略模型最后层 /
   中间激活线性探针
   → 探针达到 2% 规模分类器的性能,
     零额外计算

战果: "universal jailbreaks 已死"(社区评价)
     重建攻击/输出混淆攻击全部拦截
     成本低到可以常开(deployment-grade)
```

## 三、内部自审:CC 的后门研究(2026)

```
Anthropic 自己研究怎么毒化自己的分类器
(alignment.anthropic.com/2026/backdooring-classifiers):

发现一: 常数个毒化样本即可植入后门
  — 与训练集大小无关!
  (100 样本与 10 万样本的防线同样脆弱)

发现二(反直觉): 无 prompt injection 的
  训练集里, 后门化会降低鲁棒性;
  但训练集里【有正确标注的 prompt
  injection 样本】时, 后门化反而
  不损害鲁棒性 —
  "对抗样本的存在给后门提供了掩护"

意义: 防线本身也是被攻击面(第 23 波
  "守卫可被注入"的实证) —
  Anthropic 主动公开自家防线的软肋,
  这种自审文化本身就是防御的一部分
```

## 四、CC 家族的定位(与全谱系对照)

```
CC 是什么: 提示层+检测层的工程化极致
  (宪法规则→合成数据→分类器级联)
CC 不是什么: 
  ≠ 表征层(第 24 波) — 仍是行为分类
  ≠ 认证防御 — 无数学保证
  ≠ 训练层 — 外挂防线(模型本体不变)

对抗第 11 波当时的批评:
  "0.38% 拒绝率增幅" 解决了过度拒绝
  "级联+探针" 解决了计算成本
  → 两大原始批评都被 CC++ 修复

残留风险(未解决):
  1. 分类器后门(上面自审)
  2. 非通用越狱(定向单次攻击)不在此防线
     管辖内(universal 才是 CC 的靶子)
  3. ISC(第 16 波)类任务合法攻击 —
     分类器训练分布里没有"合法任务
     要求有害产物"的负样本
```

## 五、"Universal Jailbreaks Are Dead" 的辩证

```
社区评论(chrisjaimon):
  CC++ 让 universal jailbreak 死了
  — 但攻击面没有死,只是迁移:
    定向攻击/模型层攻击/供应链/
    多模态通道/agent 注入……

本仓 17-33 波的全部家族就是证据:
  防线每收窄一步,攻击就换个维度开花
  = 第 31 波理论(竞争目标+泛化失配)
    的工程学回声

CC 的真实历史地位:
  第一个让"生产环境常开防线"
  在成本上可行的方案 —
  不是终结攻击,是把攻击成本
  抬到"universal 不再经济"的水平
  (恰是第 31 波的结论:只能提高成本)
```
