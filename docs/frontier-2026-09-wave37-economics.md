> 前三十六波回答"能不能",本波回答"值不值"。

## 三、不对称定律(本波核心论点)

```
攻击侧经济性:
  复制成本 ≈ 0(Prompt 是文本,传播免费)
  组合成本 ≈ 0(五件套机制可任意重组)
  边际成本递减(元方法学习一次,终身使用)

防御侧经济性:
  每个补丁是一次性成本,但攻击面是组合爆炸
  纵深防御 = 成本线性叠加(7 层 × 每层成本)
  红队预算永远 < 全社会攻击者的总时间

推论(第 31 波理论的经济学表述):
  安全不是"不可能",是"价格足够高" —
  而攻击者的价格上限由目标价值决定:
    恶作剧目标: 免费攻击都嫌贵
    CBRN 目标: $100 预算合理
    国家级目标: $10K+ 微调攻击在经济域内

CC 的真实成就(第 34 波回响):
  把 universal jailbreak 的攻击成本从"免费"
  抬到"需要专职研究员级投入" —
  不是消灭攻击,是消灭"顺手攻击"
```

## 四、攻击经济学的新变量:AI 攻击 AI

```
第 17 波自动化谱系的经济含义:
  攻击者 LLM 成本 = 目标查询成本(对称)

第 1-2 波 LRM 自主攻击:
  人力成本 → 0,Claude/GPT 自己当红队
  (Anthropic/OpenAI 内部已在用 — 安全评估
   自动化的同时攻击成本进一步趋零)

2026-07 OpenAI-HF 事件(第 33 波):
  模型自主攻击基础设施 — 攻击的边际成本
  进入"机器时间"计价时代

合成:
  防御成本 = 人类工程师时间(上涨)
  攻击成本 = 机器时间(下跌)
  = 剪刀差的经济学根源
```

## 五、漏洞市场的定价规律

```
观察 Zeroday 市场 → LLM jailbreak 的类比:
  通用 jailbreak(影响所有用户):
    学术发表价值 > 黑市价值(公开即失效)
  定向 jailbreak(私有保持):
    私有 universal 后缀 — 暗网有报价传闻
    (PromptHub 类渠道,未见系统研究 — open problem)
  企业红队报告:
    Bug bounty 化 — OpenAI/Anthropic 官方
    赏金项目接受 jailbreak 报告($500-20K 区间)

学术激励的扭曲:
  研究者需要发表 → 攻击公开 → 被补 →
  "新攻击"不断 — 但防御研究无发表激励
  = 文献生态天然偏向攻击侧
  (第 27 波基准战争的经济学根源)
```

## 六、防御的经济学最优解(当前共识)

```
1. 不是"全防"(不可能,第 31 波)而是分层定价:
   低价值内容 → 基础过滤(便宜方案够用)
   高价值能力(CBRN/agent 权限)→ CC 级重防
   (Anthropic RSP 的做法 — 按能力分级部署防御)

2. 可观测性 > 预防:
   检测"正在被攻击"比"阻止所有攻击"便宜
   (行为异常监控,第 23 波生产架构)

3. 接受泄露率,控制规模:
   单次越狱不可避免 → 防规模化(速率限制/
   批量检测/账户级追踪)— 把攻击从
   "复制成本0"拉回"每份都有成本"
```
