## 二、SAE×安全的应用谱系

### 拒绝机制

```
Refusal SAE 研究(2505.23556):
  识别因果中介拒绝行为的潜特征 —
  干预验证: 关掉特征 → 拒绝消失
  (第 7 波方向工程的 SAE 精细版)

拒绝特征选择(2604.01604):
  现有方法按激活强度选特征 —
  抓到的是表层信号不是因果特征
  → 因果导向的重新选择
```

### 越狱定位

```
Vulnerable Features(2604.23130):
  从全局方向/steering 向量下沉到
  【prompt 条件化的 SAE 特征】级定位 —
  越狱脆弱性的细粒度机制图谱

电路发现检测(2608.27504):
  越狱电路(attention head 组合)定位 —
  与 SAE 特征互补的电路级视图
```

### 检测防御

```
CC-Delta(2602.12418, 第 24 波):
  配对 harmful/jailbreak 提示的
  统计检验选特征 + SAE 潜空间均值转向

Safe-SAIL(ACL 2026 F):
  安全域特征景观 — 低频概念域的
  SAE 选择 + 特征解释成本问题

SALO 拒绝轨迹(2605.02958):
  因果追踪发现"拒绝轨迹" —
  上游稀疏激活模式【在 GCG 攻击
  压制终端拒绝信号后仍然存留】!
  → 潜在拒绝轨迹 = 鲁棒检测新通道
  (攻击压住了行为,压不住轨迹)
```

## 三、泼冷水:SAEGuardBench(2026-04)

```
"Do SAE Features Actually Help Detect Jailbreaks?"
  8 种检测方法 × 4 范式 × 6 数据集 × 4 模型(2B-70B)
  结论: SAE 特征的越狱检测
       【一致地差于简单的 logit 探针】!
  
意义:
  ① 可解释性 ≠ 检测效力 — 精细特征
     的信息可能已被简单探针捕获
  ② SAE 的安全价值或在【干预】(steering)
     而非检测 — 定位工具不是分类工具
  ③ 基准必要性再证(第 27 波精神):
     直觉好的方法需要横向对照
```

## 四、架构演进(2026)

```
Subspace-Aware SAE(2606.06333):
  单 decoder 方向假设 vs 特征内在
  多维结构 — 根本张力
  → 证明该张力导致特征分裂(两种机制)
  → 子空间感知 SAE 修复

AdaptiveK(ACL 2026 F):
  固定稀疏度 → 语义复杂度自适应
  (简单句少特征,复杂句多特征)

安全分类迁移(EMNLP 2025):
  SAE 特征在安全关键分类的
  层选择/宽度/pooling 系统分析 +
  跨模型迁移性

DACC 多模态(CVPR 2026):
  字典对齐概念控制 — 冻结模型的
  推理时激活转向,护航 MLLM
  (第 25 波视觉防御的 SAE 版)
```
