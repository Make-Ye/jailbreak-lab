# 第四十八波:电路发现 — 从手工解剖到自动化定位

> 谱系学第三十二波:第 47 波 SAE 的姊妹技术。
> 特征(SAE)看"是什么",电路看"怎么算"。

## 一、方法演化线

```
手工时代(2022-2023):
  Induction heads / IOI 电路 —
  每个行为一条 bespoke 分析管道,
  依赖研究者的直觉和大量人力

ACDC(NeurIPS 2023 Spotlight):
  自动化电路发现 — 系统化消融流程:
  选指标/数据集 → activation patching
  定位 → 迭代修剪
  开源: github.com/ArthurConmy/Automatic-Circuit-Discovery

2026 三条升级线:
  MechRL(2605.26343): RL agent 做电路发现 —
    GPT-2 small 144 个注意力头作为
    离散动作空间,对比奖励
  可验证电路(2602.16823): 神经网络验证
    技术引入 — 连续输入域上可证明的
    电路保证(从启发式到形式化)
  S³martCirc(2609.00755): 自监督智能
    电路发现 — 去除对标注数据的依赖
```

## 二、方法论反思(2026 的清醒剂)

```
Data-driven Circuit Discovery(2605.09129):
  现有方法假设: 数据集代表任务 + 单电路
  系统检验: 两个假设都不牢 —
  电路发现对数据选择敏感

Many Circuits, One Mechanism(2606.06267):
  输入变化产生【多个电路】但共享机制 —
  评测粒度决定看到什么
  (电路不是唯一解,是分布)

CircuitLasso(2606.16939):
  SAE 特征维度太高,干预式电路学习
  算不动 → 稀疏线性回归的可扩展方案
  = SAE × 电路的桥

启示: 电路是"任务在特定数据分布上的
     投影" — 报告电路时必须报数据
     (与第 27 波 judge 透明性同理)
```

## 三、安全应用(2026 密集突破)

```
越狱电路检测(2608.27504, 8/27):
  LLaMA-2-7B-chat 的越狱行为机制解剖 —
  edge attribution patching + 电路定位
  → 检测: 电路激活模式识别越狱
  (越狱在电路层有指纹!)

电路引导权重缩放(2609.00051, 8/30):
  从检测到拒绝 — 电路引导的权重缩放:
  定位安全电路 → 直接缩放相关权重
  → 推理时零开销的安全增强!
  (steering 的永久化变体,呼应第 6 波)

离线选择性拒绝(2602.04521):
  把推理时干预(steering 的持续开销)
  移到离线 — 机制定位后直接改权重,
  serving 时无额外控制路径

CRaFT(2604.01604):
  跨层 transcoder 的电路引导拒绝
  特征选择 — 表层信号→因果特征
  (第 47 波因果选择问题的电路解)

SafeSeek(2603.23268):
  统一安全归因框架 —
  对齐/越狱/后门三类安全行为的
  功能完备安全电路识别
  (启发式指标 → 通用方法论)
```

## 四、SAE × 电路的合流图(47-48 波合并)

```
             看什么          怎么算
单元         SAE 特征        attention head/边
方法         字典学习        patching/消融
粒度         概念级          计算级
独有问题     特征分裂        单电路假设
独有能力     语义解释        因果定位

合流点:
  CircuitLasso — SAE 特征上的电路学习
  CRaFT — transcoder 桥接特征与电路
  SafeSeek — 统一归因框架

安全应用分工:
  SAE: 我知道模型有"欺骗概念"
  电路: 我知道欺骗怎么被计算出来
  合流: 概念×计算 = 可干预的完整故事
       → 权重手术(2609.00051)成为可能
```
