## 二、攻击家族(六型)

```

```

```
  仓库)→ 存入记忆 → 休眠 → 未来某刻
  悄悄塑造真实动作
  (针对个性化助手的持久化后门)
```

### 3. Zombie Agent 僵尸代理

```
2602.15654:

    进化能力 = 感染能力
```

## 三、防御:权威性难题

```
Securing LLM-Agent Memory(2606.24322):
  现有防御两族全破:
  ① 内容型(检测/信任评分) — 内容可伪造
  ② 血缘型(lineage 追溯) — 历史可混淆
  → 提出: 不可篡改的来源绑定权威性 +
    机器检查保证
  (密码学方法进入 agent 记忆安全)

结构性困境:
  记忆的价值 = 跨会话信任累积
  记忆的风险 = 恶意内容同样跨会话累积
  = "持久性"本身是双刃剑 —
    功能与漏洞同源,不可分割
  (与第 16 波 ISC"任务能力即漏洞"、
   第 31 波"安全-效用权衡"同构:
   记忆版的结构性结论)
```
