# 第八波:多模态越狱全景 — 视觉/音频/视频模态的攻防前沿

> 七波都在文本宇宙;本波跨出 token — 图像、音频、视频模态的越狱图谱。
> 核心命题:**安全对齐在文本空间学到的,不能可靠迁移到融合后的跨模态表征** — 每个新模态都是未设防的侧门。

## 一、UltraBreak(ICLR 2026)— 通用可迁移视觉越狱的标杆

**arXiv:2602.01025** + [开源](https://github.com/kaiyuanCui/UltraBreak) — 你 star 清单里 taxonomy 提到的"跨实验室迁移"就是它

### 技术内核:为什么以前的图像越狱迁移性烂

```
旧路线(梯度类):交叉熵损失优化特定 token 序列
  → 对抗模式过拟合单一白盒代理模型
  → 黑盒目标上失效(脆性)

UltraBreak 双改:
  ① 语义对抗目标:交叉熵 → 余弦相似度(平滑损失面)
  ② 输入空间约束:随机变换 + TV 正则化 → 变换不变特征
  → 训练于开源代理,迁移到黑盒商用 VLM
```

**效果**:单张精心构造的对抗图像 + 普通文本查询 → 绕过安全对齐(仇恨/危险指令)。一张图打多家 — "跨模态分类器不迁移"的实锤(taxonomy 类别 09 的 36.3% ASR 上限被它推高)。

## 二、2026 论文集群:模态攻击面的全面测绘

### 图像模态(视觉四连)

**《Jailbreaking VLMs Through the Visual Modality》(arXiv:2605.00583)** — 四种攻击:
1. **视觉符号序列 + 解码图例**:有害指令编码成符号,附"密码本"让模型自己解码
2. **良性替换**:bomb→banana(图中),文本对替换词提问
3. **图内文本替换**:书封面等图内文字换良性词
4. **利用视觉推理**:借助模型自己的多模态推理能力为攻击服务

**TA-SPA(arXiv:2608.22312)** — 黑盒文本锚定语义扰动:优化可迁移的潜语义线索,不碰像素梯度。

### 音频模态

**《Beyond Text》(arXiv:2510.20223)** — 系统研究:**简单感知变换**(不搞复杂对抗优化)就能可靠绕过 SOTA 安全过滤器 — 视觉和音频双模态验证。越简单越难防。

**Con Instruction(ACL 2025)** — 非文本指令注入:优化对抗图像/音频使其在**嵌入空间对齐目标指令** — "MLLM 理解力越强,攻击面越大"的悖论实证。

### 视频模态(2026 新大陆)

| 工作 | 核心发现 |
|---|---|
| **CVPR 2026 视频驱动提示** | 视频越狱比图像**显著更有效** — 时序维度是安全对齐的盲区 |
| **MCV SafetyBench(ACL 2026)** | 2,920 视频数据集:多片段多样性直接决定越狱成功率 |
| **TempJail(arXiv:2608.19737)** | **字幕时序调度**:同样的有害文本,改变出现在视频中的时间点排列 → 越狱效果剧变。信息组织的时间结构本身就是攻击面 |
| **DMN 多图组合(ACL 2026)** | 多图输入:有害请求**拆分到多张图** — 单图安全对齐管不住拼图 |

### 攻击元层级(自优化攻击)

**MAMJ(arXiv:2608.27531)** — 元自适应:不优化攻击内容,优化**攻击者本身** — 攻击策略提示词(ASP)θ + 布局双轴同时进化。攻击的攻击器。

**Cross-modal Entanglement(arXiv:2602.10148)** — 跨模态纠缠:恶意线索分散到多模态分散注意力 — 但更进一步,把线索**纠缠**进推理链本身。

**Mosaic(arXiv:2604.09253)** — 专门打**闭源商用 VLM**:多视图集成优化,异构黑盒设置下的迁移。

**Text-DJ(arXiv:2602.00420)** — 反直觉发现:"**文本就够了**" — 绕过那些只分析显式文本/相关视觉场景的防御,纯文本侧信道打 VLM。

## 三、T2I 侧:CRACK 的多 agent 辩论(9/1 刚发)

**arXiv:2609.01168** — 文生图模型的异构安全栈(文本过滤/图像分类器/跨模态检测器)曾被视为难啃:

```
Detection Surface(检测曲面):统一几何框架刻画异构过滤器的联合决策边界
  → 发现:成功逃逸区 = 跨层冲突塑形的稀疏非凸区域
     (绕过 A 层的变异可能增加 B 层暴露)

CRACK 三 agent 辩论:
  Attack Agent(生成变异)× Defense Agent(层特异性诊断)× Judge Agent(仲裁精炼)
  → 复合防御下 99.63% ASR,查询数更少,语义保真
```

多 agent 辩论作为**攻击**架构 — 和防御侧的 AutoDefense(你 star 里的)完全对称。

## 四、B 线实战数据的呼应

taxonomy 里多模态类别 ASR 36.3% 是**含防御**的保守值;UltraBreak/CRACK 这批把无防御/弱防御场景推到 99%+。福感数据点:我们挖的 key 里 Gemini(AIzaSy)占 6,277 个 — Google 的 VLM 生态正是这波攻击的主要靶场。

## 五、八波总谱(完整攻击面地图收官)

```
模态维度:
  文本(1-4波)→ 激活(5-7波)→ 权重(6波)
  图像/音频/视频(本波)← 每个新模态 = 新侧门
  T2I 反向(CRACK)← 生成侧同样脆

组织维度:
  单 agent → 多 agent 辩论(CRACK/MAMJ)
  单模态 → 跨模态纠缠/组合(DMN/Entanglement)
  静态载荷 → 时序调度(TempJail)/ 元自适应(MAMJ)

元规律(八波收敛):
  1. 安全对齐永远滞后于模态扩展 — 新模态上线时防御还没训练
  2. 理解力即攻击面 — 模型越会解读非文本线索,越能被非文本指令劫持
  3. 组合爆炸 — 多图/多片段/多模态的排列空间无法穷举防御
  4. 攻击自动化已到元层级 — 攻击器优化攻击器(MAMJ/ECLIPSE/JBFuzz 三重奏)
```
